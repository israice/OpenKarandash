## ПРОВЕРКА АРХИТЕКТУРНЫХ ИНВАРИАНТОВ

1. **Циклических связей нет** — `madge --circular server.js`, входит в `npm run check`.
2. **Направление зависимостей** — `server.js` только разворачивает `createRoutes()`;
   фичи не знают про ядро.
3. **Один ответственный за разметку компонента** — разметка на сервере (шаблон `.eta` +
   маршрут `/api/fragment/*`), клиент только вешает обработчики. Пункт 3
   `DOCS/целевая-архитектура.md` (переезд компонентов на шаблоны) закрыт в v0.0.161–171.
4. **Размер файлов** — правило 022 (~150–300 строк, за 400 — делить); предупреждение
   `npm run check` показывает файлы длиннее 400.
5. **`vh`/`vw` только в `SYSTEM/styles/base.css`** — проверяется автоматически.
6. **Граница запроса** — только localhost/loopback плюс проверка `Origin`
   (`DOCS/decisions/103`), сервер не слушает наружу.
