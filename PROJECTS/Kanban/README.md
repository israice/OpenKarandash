# 🗂️ Kanban

Вкладка сейчас — чистая UI-заготовка (`DOCS/decisions/032`): никакой доски
оркестратора, никакого встроенного beads-web, никакого сервера вообще. Пять
пустых колонок статуса, вид которых меняется по шагам — что попросит
пользователь следующим, то и добавляется.

## 🧭 Что это сейчас

Одна из вкладок Mission Control — кнопка тулбара `kanbanButton`, вид
`kanbanView`, весь код в `PROJECTS/Kanban/kanban.js`. Разметку колонок строит
сам этот файл при загрузке страницы — ни `hx-get`, ни серверного маршрута, ни
базы данных за вкладкой больше нет.

## 🧱 Колонки

Пять пустых колонок-заглушек: `Todo`, `In Progress`, `Blocked`, `Review`,
`Done`. Без карточек, без счётчика, без клика — это только каркас, на который
будет ложиться то, что опишет пользователь.

## 📁 Файлы

| Файл | Что делает |
|---|---|
| `PROJECTS/Kanban/kanban.js` | Строит разметку пяти пустых колонок в `#kanbanView` |
| `PROJECTS/Kanban/kanban.css` | Стиль вида вкладки и колонок |
| `SYSTEM/index.html` | Пустой контейнер `#kanbanView`, кнопка `kanbanButton`, `<link>` на стили |
