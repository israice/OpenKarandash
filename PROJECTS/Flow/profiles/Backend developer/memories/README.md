# memories/ — Backend developer

Память этого работника между заданиями.

`skills.md` — приёмы, которые уже сработали: агент дописывает их в конце задачи
(`POST /api/flow/profile/memory/add`, серверная половина —
`PROJECTS/Flow/profiles-server.js`) и читает в начале следующей, чтобы не
выводить заново то, что однажды вывели. Файл версионируется вместе с кодом:
в `.gitignore` под профилями ловятся только runtime-файлы (`auth.json`,
`sessions/`, `npm/`, `git/`), а опыт работника — часть проекта.
Подробности — `DOCS/decisions/035`.

Остальная кросс-сессионная память Hermes (`memory.provider` в `../config.yaml`)
пока не заведена: настоящие ходы идут не через профиль (`DOCS/decisions/033`).
Память проекта, не принадлежащая ни одному работнику, — в `DATA/vault`
(`AGENTS.md`).
