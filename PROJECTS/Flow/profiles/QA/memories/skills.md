Приёмы, которые уже сработали в этом проекте. Дописывает агент в конце задачи,
читает — в начале следующей, чтобы не выводить заново то, что однажды вывели.
Запись стоит делать, только если приём проверен: не «наверное, помогает», а
«сделал так — получилось, вот чем подтверждено».

## Проверять живой интерфейс, а не только разбор файла

- **Когда применим:** Правка клиентского файла вкладки завершена, node --check прошёл
- **Что делать:** node --check видит только синтаксис. Обращение к необъявленному имени ловит npm run check (правило no-undef), а упавший обработчик и пустую панель — только живой прогон вкладки на сервере, поднятом пользователем (DOCS/decisions/002).
- **Чем подтверждён:** В flow.js жило обращение к ненаписанной ROOT_FIELDS: node --check проходил, панели карточек упали бы у обеих ролей сразу
