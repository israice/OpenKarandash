# Penpot

Страница с канвасом Penpot: `page.js` встраивает редактор в iframe и держит
соединение с MCP. Имя страницы в самом Penpot тоже `Penpot` — переименовано
вместе с папкой, чтобы искать можно было по одному слову.

Права на просмотр канваса выдаёт `TOOLS/penpot-mcp/grant-access.mjs`: свой
аккаунт состоит в команде макета редактором, поэтому iframe открывается без
приглашения и письма.

Макеты лежат в файле Penpot, а не здесь: сборка и проверка — в
`TOOLS/penpot-mcp/design` (`node build.mjs --check`).

Иконка кнопки страницы — `page-icon.svg` рядом: рамка с горкой и солнцем. Файл
можно заменить на свой, правило — в `DOCS/decisions/083`.
