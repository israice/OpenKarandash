# Правила проекта: Измерения и упрощение

Часть `AGENTS.override.md`, разложенного по темам: горячие правила и маршрут по типу задачи лежат в самом `AGENTS.override.md`, остальное — здесь. Читать, когда конец задачи: как не тратить шаги и контекст.

## Измерения и упрощение

Поиск, домашняя работа, чтение без нужды, `npm run check` и запрет грести мусор живут в горячем файле и в `карта-проекта.md` — здесь только то, чего там нет.

- **Короткий вывод.** По запросу анализа сессии — 2–4 пункта с конкретными предложениями, без воды.
- **Без автоматических прогонов.** Не предлагай добавлять новые smoke/автотесты/большие серверные прогоны. Смоук удалён (025). Проверки — точечные (`node --check`, eslint/madge, `npm run check`, `npm run ui`/live-verify) там, где они действительно ловят ошибки.
- **Дамп всего списка вместо двух пунктов.** У селекта 50 пунктов, вернулось 450 строк JSON ради пары цветов — теперь это делает готовый сценарий `styles`, четыре числа.
- **Снимок там, где нужны были числа.** Два PNG на раскрытый список `select`, а нативный попов в снимок не попадает в принципе: проверить им было нечем.
- **Лишние шаги меряются по базе, а не на глаз.** `node TOOLS/steps/run.mjs` считает по последним сессиям, сколько шагов инструмента ушло впустую и по каким видам: цифра «было → стало» и есть доказательство, что правка сработала. Без этого числа любое утверждение «стало лучше» в записке решения голословно.
- **Консоль вместо инструмента чтения.** Русский текст из консоли приходит кракозябрами — лишняя итерация; состояние дерева бери с путями, `git status --porcelain -- <пути>`, иначе оно даёт сотни чужих правок других сессий.
