# Удаление неиспользуемых файлов

## Контекст

Проверка размера проекта показала, что рабочий код использует зависимости и
данные, а три корневых файла не имеют ссылок из текущего кода или конфигурации:
`list_of_providers.csv`, `kilo.json` и `skills-lock.json`.

## Решение

Удалить эти три файла. `opencode.json` сохранён: его может читать внешний CLI при
запуске из корня проекта, даже если приложение напрямую его не импортирует.

## Последствия

Проект больше не хранит устаревший список провайдеров, пустую конфигурацию Kilo
и пустой lock-файл навыков. Исторические упоминания в документации не изменяются.

Проверено: `npm run check` проходит; поиск по текущему коду не находит ссылок на
удалённые файлы.
