# Сервер не запускают из сессии агента

**Решение.** `node server.js` из сессии CLI не запускается ни в фоне, ни на переднем плане; запуск блокирует хук `.claude/hooks/no-bg-server.js`. Сервер для себя пользователь поднимает сам.

**Почему.** Без `NO_RELOAD=1` поднимается сторож с дочерним процессом. На Windows завершение сессии не шлёт им сигналов — оба остаются жить. Осиротевший сторож держит cwd проекта (папку нельзя переименовать), сутками опрашивает файлы и дерётся за `DATA/.sessions.db` со следующей копией — см. [001](001-один-порт-одна-копия.md).

**Чем платим.** Агент не может посмотреть на работающее приложение. Раньше вместо этого был смоук, но с [025](025-смоук-удалён-автопроверок-нет.md) он удалён: остаются разбор файла (`node --check`), живая проверка в браузере на сервере пользователя и агент `ui-checker`.
