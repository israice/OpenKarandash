# Сервер не запускают из сессии агента

**Решение.** `node server.js` из сессии CLI не запускается ни в фоне, ни на переднем плане; запуск блокирует хук `.claude/hooks/no-bg-server.js`. Правки проверяются смоуком `node SYSTEM/smoke.js`, сервер для себя пользователь поднимает сам.

**Почему.** Без `NO_RELOAD=1` поднимается сторож с дочерним процессом. На Windows завершение сессии не шлёт им сигналов — оба остаются жить. Осиротевший сторож держит cwd проекта (папку нельзя переименовать), сутками опрашивает файлы и дерётся за `DATA/.sessions.db` со следующей копией — см. [001](001-один-порт-одна-копия.md).

**Чем платим.** Агент не может посмотреть на работающее приложение и проверяет себя только смоуком. Поэтому у каждого нового маршрута обязан появиться свой `check(...)` в `SYSTEM/smoke.js` — других автоматических проверок в проекте нет.
