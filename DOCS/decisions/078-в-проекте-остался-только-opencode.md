# 078. В проекте остался только OpenCode — чужие оболочки и трекер задач убраны

## Решение

Решения `074` и `075` убрали из интерфейса коннекторы Claude, Codex и pi.
Эта записка убирает то, что от них осталось в самом репозитории: не провайдеры,
а их оболочки и то, чем они пользовались.

**Убрано из git:**

| Что | Почему |
|---|---|
| `.claude/` — 62 файла: `settings.json`, 13 субагентов, 20 хуков, 7 навыков, справка оркестратора | оболочка Claude Code; агента в проекте нет (`074`) |
| `.codex/` — `config.toml`, `hooks.json` (оба звали `bd codex-hook`) | оболочка Codex (`075`) |
| `CLAUDE.md`, `CLAUDE.override.md` | правила, которые читает только Claude Code; общие уже в `AGENTS.override.md` |
| `skills-lock.json` | пин стороннего навыка `create-beads-orchestration` из `The-Claude-Protocol` |
| `.beads/` — 8 файлов (хуки git, `config.yaml`, `metadata.json`) | трекер задач beads, которого в проекте нет |

**Убрано с диска, в git их не было:** `.kilo/` (рабочая копия Kilo Code и его
правила в `.git/info/exclude`), `.commandcode/`, `.playwright-mcp/` (логи
браузерного MCP — по решению `048` его в проекте нет), `.agents/skills/beads/`,
`.worktrees/` и `.claude/worktrees/` (четыре записи `git worktree`, все
`prunable`), `__cut.cjs` (одноразовый скрипт правки), а из `.git/info/exclude` —
14 строк про Kilo Code.

**Перенесено в `TOOLS/`** — то, что работало и не было Claude:

- `TOOLS/live-verify/` — `run.mjs` и четыре сценария (`open`, `connect-cli`,
  `short-turn`, `three-views`), бывшие `.claude/skills/live-verify/`. Описание
  сценариев стало `README.md` вместо `SKILL.md`: осталось документацией папки,
  а не навыком конкретного агента.
- `TOOLS/next-numbers.js` — считает следующую версию и номер записки решения.

**Поправлены ссылки на удалённое:** `eslint.config.mjs` (в списке серверных
файлов `.claude/hooks/**` и `.claude/skills/finish-task/*.js` заменены на
`TOOLS/next-numbers.js`; из `ignores` ушли `.claude/worktrees/**` и
`.worktrees/**`), `SYSTEM/checks.js` (`SKIP` — три папки, а не семь), `.gitignore`
(строки beads, `.playwright-mcp`, `/.agents/`, `/.worktrees/`,
`/.claude/worktrees/`), `server.js` (две ссылки в комментариях), `README.md`
(раздел о параллельных ходах и карта папок), `AGENTS.override.md` (первая
строка, правило автокоммита, правило про хуки, правило про проверку, запрет
запуска сервера) и два блока `BEADS INTEGRATION` / `BEADS CODEX SETUP`, вклеенные
в `AGENTS.override.md` командой `bd setup`.

## Почему

Провайдеры убрали решением владельца, а оболочки остались — и выглядели
рабочими. `.claude/settings.json` с двадцатью хуками читается как работающая
настройка, хотя ни один агент, который её читает, в проекте не остался. Хуки
поддерживали правила, которые важны и сейчас: `commit-guard` (не коммитить
оптом, гонять проверку), `syntax-check` (разбор после правки), `no-bg-server`
(запрет запускать сервер из сессии). Удалив папку молча, мы потеряли бы эти
правила вместе с ней — поэтому они переписаны текстом в `AGENTS.override.md`:
правило, написанное в правилах, работает при любом агенте, а хук — только у
того, кто его умеет читать.

Beads ушёл по факту: CLI `bd` на машине не установлен, его рабочие копии
прозрачны, а сгенерированный им блок правил в `AGENTS.override.md` требовал от
агента того, чего он не может сделать. `024`-е правило протокола beads в
`DOCS/decisions/026` осталось в истории — как и заметки про `.claude/`.

## Чем платим

- **Механической страховки при коммите больше нет.** `commit-guard` отказывал в
  `git add -A` и гонял `SYSTEM/checks.js` перед коммитом; теперь это держится
  только на правиле. Правило в `AGENTS.override.md` переписано соответственно:
  `npm run check` — обязательный шаг, а не страховка.
- **Разбор синтаксиса после каждой правки делает `npm run check`, а не хук.**
  Заодно из проверки ушло то, что смотрел только хук: `.mjs`/`.cjs`, строгий
  `.json` и Python. Правило дописывается в текст при необходимости.
- **Субагенты, навыки и помощники Claude Code в проекте не вернутся** без нового
  решения. `ui-checker` и `live-verify` как навыки — тоже: сценарии живут, но
  вызываются через node.
- **Записи `git worktree` владельца теперь придётся заводить самому.** Папки
  `.worktrees/` больше нет, `npm run branches` и `branch-gate` работают с любым
  путём копии (`git worktree list --porcelain`), но копия, созданная как
  `git worktree add`, снова не попадёт в git — как и раньше, только папки-исключения
  в `.gitignore` для неё больше нет.
- `PLAN.md` и `TASKS.md` остались как есть: это документы о состоянии проекта на
  момент их написания, и переписывать их под текущий код — значит врать о
  истории замеров.

## Что проверено

`npm run check` — чисто (eslint, madge, счёт длинных файлов). `node
TOOLS/next-numbers.js` из нового места работает и печатает `v0.0.94` и номер
записки `078`; `node TOOLS/live-verify/run.mjs` без аргументов печатает свой
список сценариев (код 2, как и раньше) — оба находят корень через `../..`.
Живьём интерфейс не проверялся: правки не трогали код интерфейса, а сервер,
который поднял владелец, агент не поднимает.
