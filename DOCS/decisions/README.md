# Решения

Короткие записки о том, **почему** в проекте сделано так, а не иначе. Отвечают на вопросы, ответ на которые из кода не виден и который иначе выясняется заново каждый раз.

Лежат в репозитории, а не в `DATA/vault/` — так они версионируются вместе с кодом и всё равно попадают в поиск (`node PROJECTS/Graph/search.js "запрос"`) и в граф: сервер обходит все папки проекта, кроме `.git` и `DATA/`.

Правила: одна записка — одно решение; формат «Решение / Почему / Чем платим». Отменённое решение по умолчанию не удаляем, а помечаем в самой записке — но если решение снимает целый слой кода, записки этого слоя удаляются, а новая перечисляет их номера: держать в репозитории описания того, чего в проекте нет, незачем. Номера освободившиеся не переиспользуются.
