# Смоук удалён, автоматических проверок в проекте нет

**Решение.** `SYSTEM/smoke.js` удалён вместе с npm-скриптом `smoke`. Автоматических проверок в проекте больше нет и заводить их обратно по одному маршруту не нужно. Серверный файл после правки проверяется разбором — `node --check <файл>` (это же делает хук `.claude/hooks/syntax-check.js`), а работает ли фича на самом деле, видно только в браузере на сервере, который поднял пользователь. Живой интерфейс при необходимости проходит агент `ui-checker` через Playwright MCP.

**Почему.** Так решил владелец проекта: смоук — лишняя трата времени. Он проверял только HTTP-уровень (546 строк, 35 проверок: страница отдаётся, 404/403/405 на месте, маршруты отвечают) и не заглядывал туда, где ломается основное, — в браузер. Зато цену требовал постоянную: каждый новый маршрут — свой `check(...)`, каждый переезд файла — правка прогона, а сам прогон поднимал сервер и пересобирал vault (`prepareVault()` синхронна и занимает ~20 с на этом проекте).

**Чем платим.** Между правкой и сломанным интерфейсом не остаётся ничего автоматического: регрессия в маршруте вылезет у пользователя, а не в прогоне. Компенсируем тем, что и раньше делало основную работу: разбор файла (`node --check`) ловит синтаксис, `ui-checker` — клиентскую часть, а сам пользователь держит сервер запущенным и видит поломку сразу. Если проверки понадобятся снова, заводить их стоит не HTTP-прогоном всего сервера, а точечно — там, где правило живёт отдельной функцией (как `SYSTEM/core/git-head.js`).

**Что осталось от смоука в коде.** `DATA_DIR` (`PROJECTS/Graph/graph-vault.js`) заводился ради прогона, но оставлен: он же нужен любой второй копии сервера, чтобы не драться за `.sessions.db`/`.index.db` с рабочей — [001](001-один-порт-одна-копия.md). `BEADS_PORT=0` — обычная настройка `.env`, смоук ею только пользовался. Убран один настоящий хвост: реэкспорт `noteName` из `PROJECTS/Graph/graph-server.js` существовал только для прогона.
