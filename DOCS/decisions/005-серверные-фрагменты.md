# Часть интерфейса рисует сервер (htmx)

**Решение.** Компоненты постепенно переезжают со схемы «JSON → сборка DOM в браузере» на «шаблон `PROJECTS/<Фича>/<имя>.eta` → маршрут `/api/fragment/<имя>` → htmx подменяет кусок страницы». Первой переехала панель наблюдения на Home.

**Почему.** Разметка, рендер и обработчики одного компонента были размазаны по `index.html`, `app.js` и стилям — правка требовала держать в голове все три. У сервера и так есть все данные; отправлять их в браузер, чтобы тот собрал из них HTML, — лишний слой состояния.

**Как.** Куски адресуются через `hx-swap-oob="true"` по `id`, запрос идёт от скрытого элемента с `hx-swap="none"`. Так один ответ обновляет несколько мест страницы, а разметку и сетку менять не нужно. Обработчики кликов вешаются на контейнер, который htmx не подменяет.

**Чем платим.** Две зависимости (см. [004](004-зависимости-разрешены.md)) и период, когда часть компонентов живёт по-старому, а часть по-новому.
