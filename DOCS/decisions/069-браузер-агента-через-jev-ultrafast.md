# Браузер агента — jev-ultrafast, клон в корне проекта

## Решение

Для управления браузером берём `browser-use/jev-ultrafast`. Код клонируется в `jev-ultrafast/` в корне проекта по образцу `hermes/`: в git его нет (`.gitignore`), карта проекта его обходит (`SYSTEM/core/scan.js`). В git живёт только наша обвязка — `PROJECTS/Browser/`.

## Почему

Инструмент на Python (`uv`), а зависимости проекта — npm, и записка 004 разрешает только те, что убирают существенный объём своего кода. Свой драйвер браузера с выбором элементов писать дороже. Класть его в `package.json` нельзя, а чужой код в наш git — незачем: клон обновляется сам. Ключ TypeSafe у проекта уже есть (`SYSTEM/core/typesafe.js`).

## Чем платим

Ещё один клон с внешним обновлением и второй рантайм (Python и `uv`). Нужен ключ OpenRouter (`TEXT_MODEL_API_KEY`) — в `.env` его пока нет. Chrome стоит на Windows, а Hermes в контейнере: моста между ними нет, до него инструмент запускается на стороне Windows.

## Что проверено

Пакет ставится, импортируется, 31 офлайн-тест проходит. Настоящий браузер и платные вызовы не проверялись.
