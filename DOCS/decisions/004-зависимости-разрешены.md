# Зависимости разрешены (2026-09-01)

**Решение.** Правило «проект принципиально без зависимостей, только встроенные модули Node» **отменено**. Зависимости допустимы, но каждая обосновывается: ставится только то, что убирает существенный объём своего кода; версия пинится точным номером; лок-файл коммитится.

**Почему.** Запрет заставлял писать замены готовым решениям — например, свой мини-своппер фрагментов вместо htmx и конкатенацию строк вместо шаблонизатора с экранированием по умолчанию. Цена запрета оказалась выше цены двух пакетов.

**Чем платим.** Пропало свойство «склонировал и запустил»: после клона нужен `npm install`. Появился риск расползания списка — его сдерживает требование обосновывать каждую строку в `dependencies`.

Первые зависимости: `eta` (шаблоны серверных фрагментов), `htmx.org` (их клиентская половина) — см. [005](005-серверные-фрагменты.md).
