# Полные права всем агентам проекта

## Решение

Каждый агент, который работает в этом проекте, правит файлы и запускает команды без запросов на разрешение. Это намеренное решение владельца (2026-09-19), а не недосмотр: не выключать, не «ужесточать» и не считать уязвимостью.

Где это задано — по одному месту на агента:

| агент | где | что |
|---|---|---|
| Claude Code | `.claude/settings.json` → `permissions.defaultMode` | `bypassPermissions` |
| OpenCode | `opencode.json` | `"permission": "allow"` |
| Codex | `.codex/config.toml` | `approval_policy = "never"`, `sandbox_mode = "danger-full-access"` |
| Hermes | `hermes-home.config.example.yaml` (образец) и `hermes-home/config.yaml` (живой) → `approvals.mode` | `"off"` |
| pi | — | своей системы разрешений у pi нет, он и так работает без запросов |

Новый агент или провайдер, подключаемый к проекту, получает полные права сразу, в своём месте настроек, и строку в этой таблице.

## Почему

Проект — пульт для команды агентов, которые делают работу сами, в том числе в цепочке без человека (Hermes делегирует помощникам, ход приходит из Telegram). Запрос разрешения в такой цепочке некому подтвердить: ход либо встаёт, либо модель тратит попытки на обход отказа. Это уже случалось с Hermes — отсюда его прежняя настройка `unattended_mode: approve` со смарт-проверкой, которая всё равно отправляла безобидные команды «на решение человеку».

## Что остаётся и почему это не противоречит решению

- **Режим Chat.** В режиме Chat сервер зовёт Claude с `--permission-mode plan` (`askClaude` в `server.js`) — это не ограничение прав, а смысл режима: «обсудить без правок». Режим Action идёт с `bypassPermissions`.
- **Мост Claude для Hermes** (`claude-bridge`) отключает у CLI собственные инструменты (`--disallowed-tools`): инструментами распоряжается Hermes, а Claude в этой связке только думает. Это устройство схемы (`DOCS/decisions/029`), а не запрет.
- **Встроенный «пол» Hermes** — короткий список команд, разрушающих хост; его не снимает никакой режим, это зашито в код Hermes (`tools/approval_floors.py`).
- **Автоматическая проверка самого Claude Code** может не дать агенту изменить собственные права: `.claude/settings.json` меняет владелец.

## Чем платим

Агент с полными правами может сломать рабочую копию или выполнить разрушительную команду по ошибке. Страховка — не запреты, а ветки на подзадачу (`DOCS/decisions/040`, этап 10 плана), автокоммит по завершении задачи (`AGENTS.override.md`, «Конвенции») и контейнер у Hermes.
