# Замер перед упрощением: что можно удалять, а что держит живую переписку

**Решение.** Упрощение проекта идёт с замера использования, а не с удаления по
догадке. Замер сделан по `DATA/.sessions.db` рабочей копии 2026-10-10 (16 сессий,
752 сообщения). Первым удалено только то, что точно не вызывается: выделенный
коннектор `omp` (`SYSTEM/cli/omp.js`, 92 строки) и его `stream-core.js` (50 строк) —
142 строки, которых не требует никто. Любое слово CLI и так идёт через общий
`any.js`, а разбор вывода omp в нём есть (`SYSTEM/cli/any.js:248` —
подкоманда `models list`, `SYSTEM/cli/any-parse.js:325` — та же таблица рамкой).
В `DOCS/decisions/` ни один файл не ссылается на эти два модуля.

**Почему.** Жалоба владельца: «сделано слишком грамоздко, хотя можно было гораздо
проще». Грамотный ответ на неё — не перепись, а снятие того, что не приносит
пользы, и первым делом доказательство, что оно не приносит. Проверка доступности
обошла все `.js`/`.mjs` дерева: омертвевших модулей, кроме коннектора omp, нет —
все остальные «не найденные» ссылки игрой оказались подключены либо из
`SYSTEM/index.html`, либо из `package.json`.

**Что показал замер.** Телеграм-мост используется: `telegram_sent` 100 писем,
`telegram_replies` 208 ответов человека, `telegram_polls` 28 отвеченных опросов,
последняя активность 2026-09-23. Слои суждений: суждение о ходе записано на
24 ответах, подложенные подсказки — на 13 ходах (записки решений 5, навыки 0,
отчёт разведки 11), след хода (`judgeSteps`) пометил ход ровно один раз.
Суждения при этом держат живую переписку, а не только заметки: причина кулдауна
берётся из `knownFailure` (`SYSTEM/cli/index.js:98`), решение о письме — из
`shouldNotify`, «ждёт человека» для опроса — из суждения о ходе. Поэтому слой
удаляется только по частям и решением владельца, а не этим коммитом.

**Чем платим.** Выборка замера маленькая (16 сессий), и ноль по навыкам здесь не
доказательство ненужности — доказательством служит большее окно и замер до/после
(`TOOLS/steps/`). Пока этого нет, удалять подсказки и суждения нельзя: под ними
стоят решения живой переписки.

**Что попутно исправлено.** `json-render/` и `json-renderer/` — чужие репозитории
(48 тысяч файлов) — добавлены в `.gitignore`: из всех обходов проекта (SKIP в
`SYSTEM/checks.js`, `SYSTEM/core/scan.js`, ignores в `eslint.config.mjs`,
`SYSTEM/secrets-scan.js`) они исключены и раньше, а в git не игнорировались
никак. В `VERSION.md` склеена была строка перед `v0.0.183`: счётчик версий
(`TOOLS/next-numbers.js`) видел последней `v0.0.182` и следующая версия ушла бы
дублем.
