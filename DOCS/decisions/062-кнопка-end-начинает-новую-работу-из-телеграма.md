# 062. Кнопка END начинает новую работу из Telegram

## Решение

Нажатие ⏹ END в личке бота отвечает «Начинаем с новой сессии» и ставит личке пометку «новая работа»; выбранным режимом становится ⚡ ACTION. Первое же сообщение после этого — поручение: пульт заводит по нему новую сессию (заголовок — само поручение), снимает пометку и привязывает личку к этой сессии, так что следующие сообщения продолжают уже её. То же происходит, когда отвечать вообще некуда (ни одной работы в личке ещё не было). ASK и LOOP пока без логики.

Исполнителя, модель и режим новая работа берёт у прошлой работы этой лички; прошлой нет — первый подключённый агент. Дальше действует обычная смена исполнителя (061).

## Почему

- До этого новую работу можно было начать только из пульта: любое сообщение из Telegram уходило в последнюю сессию, и разговор о другом деле засорял чужой контекст.
- Пометка лежит в базе (`telegram_chat_state`), а не в памяти: сторож перезапускает сервер на каждой правке, и нажатие END между перезапусками терялось бы.
- Ответ reply на письмо старой работы по-прежнему идёт в неё даже после END: человек сам назвал адресата, пометка при этом остаётся.
- Пометка снимается в момент, когда сессия завелась, а не когда ход закончился: второе сообщение, посланное вдогонку, должно попасть в ту же новую работу, а не завести ещё одну. Если работа не завелась, пометка остаётся — повтор поручения не уйдёт в старую сессию.
- После END сообщение не проходит через разбор «стоп / что там / спасибо»: человек прямо сказал, что следующее сообщение — поручение.

## Чем платим

- END не останавливает идущую работу — только меняет адресата следующих сообщений. Остановить — словом «стоп» ответом на письмо работы.
- Вернуться в старую работу после начала новой можно только ответом reply на её письмо.

## Что проверено

Логика моста — на поддельных обновлениях без сети (END, отказ запуска, reply в старую, ACTION, поручение, сообщение вдогонку, первое сообщение без работ). Серверный запуск новой работы не из браузера вживую не проверен: его вызывает только настоящее сообщение владельца в Telegram.
