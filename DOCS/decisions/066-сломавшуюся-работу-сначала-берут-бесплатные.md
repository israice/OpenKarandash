# 066. Сломавшуюся работу сначала берут бесплатные модели

Уточняет 061.

## Решение

Порядок подхвата сломавшегося хода: другая бесплатная модель того же агента → бесплатная модель другого бесплатного агента (OpenCode, pi) → платные подключённые агенты. Бесплатные модели берутся из списка самого CLI (`:free`, `-free`, `/free`, `opencode/big-pickle`), список держится в памяти десять минут. За одну цепочку не больше четырёх переходов. Агент исчерпан целиком, а не одной моделью, когда не принят ключ или он не подключён; платного агента пробуем один раз. Замена происходит тихо: строка о замене в Telegram не уходит — человек видит только готовый ответ.

## Почему

- Владелец 2026-09-21: смена исполнителя нужна затем, чтобы работа доделалась, но платные подписки беречь. До этого после pi шёл первый по списку — платный Claude, хотя у pi десятки других бесплатных моделей и рядом стоял OpenCode.
- Чаще всего у бесплатной модели ломается именно модель (снята, лимит, сбой поставщика) — соседняя бесплатная решает это без денег.
- Список моделей спрашивается до первой ошибки: решение «подхватят ли» обязано быть мгновенным, по нему же глушится письмо об ошибке.

## Чем платим

- Первый ход после перезапуска ждёт список моделей у CLI (секунды, потолок 25 с).
- До платного агента теперь может пройти несколько неудачных бесплатных попыток — человек не видит промежуточных попыток, видит только готовый результат.

## Что проверено

Живьём на сервере владельца: pi с несуществующей моделью → ту же работу доделала другая бесплатная модель pi, три отображения сошлись. Переход на другой бесплатный агент и на платного после исчерпания бесплатных живьём не проверен.
