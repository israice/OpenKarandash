# 082. Список CLI с OpenRouter — один, и он же в шапке сессии

## Решение

Список названий CLI-агентов с сайта OpenRouter переехал из страницы «New
projects» в `SYSTEM/cli-agents.js` и показывается в двух местах:

- страница `PROJECTS/Page 3` («New projects») — рисует его, как раньше, и
  кнопкой в тулбаре проверяет, не изменился ли он на сайте (раз в час, условным
  запросом у сервера `openrouter-cli-agents-server.js`);
- уровень CLI в каскаде выбора модели `SYSTEM/model-cascade.js` — то есть в
  шапке сессии и в витрине вкладки Providers в Settings. Под списком OpenCode
  идёт весь список с сайта, а под ним — уже знакомая заглушка `Add`.

Пункты списка пока ничего не умеют: своего коннектора у них нет, поэтому за
ними пусто (Gateway / Provider / Model — прочерки), значение до каскада не
доходит, и ход по ним не пойдёт. По умолчанию выбран OpenCode, как и раньше.
Карточка одного провайдера в Settings (`stubOptions: false`) список не
перечисляет: там уровень CLI состоит из одного пункта.

На самой странице «New projects» строка списка — название слева, а справа
иконка подключения (штепсель, 24×24, тот же класс `.icon-button`, что и у
кнопок в тулбаре; размер свой, потому что в строке 34px занимают слишком много
высоты). Иконка пока заглушка: обработчика у неё нет, `aria-label` говорит, к
какому имени она относится, — это и есть заготовка под подключение выбранного
CLI.

## Почему

Список нужен больше чем одной странице, а держать его в странице нельзя: она
грузится динамическим import и может быть ещё не открыта, тогда как шапка
сессии нужна сразу. В `SYSTEM/providers.js` он тоже не лёг: там лежит состояние
подключения к тем CLI, которыми мы умеем ходить, а этот список — витрина
чужих имён без логики, и следующая задача — оживить кнопку `Add`, то есть
заводить по пункту настоящий коннектор.

## Чем платим

- `npm run check` сейчас падает на чужой незакоммиченной правке `server.js`
  (`DEFAULT_AGENT` в строках 1300 и 1302 не объявлен — это не наша правка), и
  поэтому коммита пока нет.
- Список на сайте меняется, а в интерфейсе он обновляется только кнопкой
  проверки на странице «New projects» и сам собой по часу; в шапке сессии новый
  список появляется сам (строка перерисовывается объявлением) или после
  перезагрузки страницы.

## Что проверено

`npm run ui` — все вкладки, страницы «+», окно настроек, замечаний нет. Живой
прогон на сервере владельца: в шапке сессии список CLI — 51 пункт (OpenCode, 49
имён с сайта, `Add`), выбран OpenCode, Gateway — `openrouter` и `Add`, ход
по-прежнему идёт `openrouter/stealth/space-bunny-alpha`; выбор пункта без
коннектора оставляет остальные уровни прочерками, а `getActiveProviderId` и
выбранная модель остаются на OpenCode. На странице «New projects» 49 строк, у
каждой иконка справа (24×24, `aria-label` = `Connect <имя>`), название прижато
влево, `text-align: left`.
