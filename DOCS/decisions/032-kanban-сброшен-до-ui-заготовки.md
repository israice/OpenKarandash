# 032. Kanban сброшен до UI-заготовки без логики

Отменяет записки о доске оркестратора и встроенном beads-web.

## Решение

По просьбе пользователя вкладка Kanban собрана заново с нуля: убрана вся
логика — чтение `hermes-home/kanban.db`, серверный маршрут `kanban-server.js`,
шаблон `kanban-board.eta`, htmx-опрос `#board` каждые 5 секунд, модалка с
деталями задачи и её лента событий/ранов/комментариев. Из всего этого не
осталось ни одного файла и ни одной строки в `server.js`.

Осталась только визуальная оболочка: `kanban.js` рисует пять пустых колонок
статуса (`Todo` / `In Progress` / `Blocked` / `Review` / `Done`) прямо в
`#kanbanView`, без сервера, без данных, без интерактивности. `kanban.css`
урезан до стилей этого каркаса — правила карточки и модалки убраны как
неиспользуемые.

## Почему так

Пользователь хочет описать вид и поведение доски заново, по шагам, а не
дорабатывать прежнюю (доску Hermes из `030` или встроенный beads-web из
`021`). Держать неиспользуемую логику до момента, пока не ясно, что из неё
понадобится, — источник путаницы: проще снести всё и наращивать по мере
того, как приходят конкретные требования.

## Чем платим

- Вкладка временно ничего не показывает, кроме пустых колонок — ни задач
  Hermes, ни какой-либо иной доски.
- Прежние маршруты `/api/fragment/kanban-board` и `/api/kanban/task` больше не
  существуют — если что-то на них ещё ссылается, это будет 404.
