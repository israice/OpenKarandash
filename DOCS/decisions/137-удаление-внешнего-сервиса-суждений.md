# Удаление внешнего сервиса суждений

## Проблема

В проекте оставалась интеграция внешнего сервиса типизированных суждений:
транспорт, API-ключ, отдельный UI-агент, диагностические скрипты и десяток
необязательных потребителей. При отсутствии ключа основной поток уже работал
через fallback, поэтому интеграция больше не была необходимой для запуска.

## Решение

Удалить транспорт и все рабочие вызовы внешнего сервиса. Необязательные
суждения, rerank, подсказки и послеходовой досмотр возвращают прежние fallback
значения; детерминированный сбор домашней работы сохраняется. Удалить также
lock-файл навыка, UI-агент и диагностические скрипты, которые требовали API.

## Последствия

Проект больше не читает ключ внешнего сервиса, не делает сетевые запросы к нему
и не зависит от его доступности. Основной запуск CLI, сервер, Telegram и поиск
продолжают работать без этого необязательного слоя.
