# Размышления Claude в headless-запуске — одним флагом, без PTY и без чтения JSONL

## Решение

Коннектор Claude (`THINKING_ARGS` в `server.js`) и мост (`claude-bridge/cli_process.py`) запускают `claude -p` с `--thinking-display summarized`. Запрет читать собственную историю CLI (`~/.claude/projects/*/*.jsonl`, `README.md` и `PROJECTS/Sessions/README.md`) остаётся в силе. PTY-обёртку не заводим.

## Замер (2026-09-19, задача f59.5)

Диалог, из которого вырос эпик f59, утверждал: в `-p` блок thinking приходит пустым, а полный текст хранит только интерактивная сессия в своём JSONL — значит, нужен PTY и чтение этих файлов. Проверено на нашем стеке (WSL-CLI 2.1.277, Windows-CLI 2.1.273), теми же флагами, какими зовёт сервер:

| где | что в блоке thinking |
|---|---|
| поток `-p`, sonnet-5 и opus-5 | пусто, одна подпись; при этом `thinking_tokens` показывает 216–247 токенов размышлений |
| JSONL этих же headless-сессий | пусто |
| JSONL всех headless-сессий машины на моделях семейства 5 (~3200 блоков) | пусто, ни одного с текстом |
| JSONL интерактивных сессий (сентябрь, opus-5 и fable-5.1) | текст есть примерно в трети блоков, и это одно-два предложения изложения («Проверяю…»), а не сами рассуждения |
| поток `-p` с `--thinking-display summarized` | текст есть — то же краткое изложение |

Первая половина утверждения подтвердилась, вторая нет: полного текста размышлений нет нигде. Интерактивная сессия отличается лишь тем, что просит у API изложение (`display: summarized`, настройка `showThinkingSummaries`), а headless по умолчанию просит `omitted`. Флаг `--thinking-display` в `claude --help` не показан, но есть в обоих установленных CLI и имеет приоритет над умолчанием.

## Почему так

PTY плюс разбор чужих файлов — это новая сущность, второй источник правды рядом с потоком и зависимость от внутреннего формата CLI. Всё, что она дала бы, даёт один аргумент запуска. В мосте флаг постоянный, как `--effort`: он часть кешируемого запроса, и менять его между ходами нельзя.

Если CLI когда-нибудь откажется от флага, запуск упадёт с «unknown option» — чинить удалением `THINKING_ARGS`, лента просто вернётся к пустым размышлениям.
