# 030. Kanban показывает доску Hermes (kanban.db), а не beads-web

Отменяет `DOCS/decisions/021`.

## Решение

Вкладка Kanban больше не встраивает npm-пакет `beads-kanban-ui` (beads-web) —
она читает настоящую kanban-доску Hermes, ту же, что видит сам Hermes при
оркестрации задач между профилями-воркерами. `kanban-server.js` открывает
`hermes-home/kanban.db` read-only через встроенный `node:sqlite` на каждый
запрос и отдаёт htmx-фрагмент (`kanban-board.eta`) с колонками по статусу
задачи. Своей разметки в `index.html` у доски не осталось — только контейнер
`#board`, который сервер подменяет целиком.

Колонки собраны из реальных статусов Hermes (`hermes_cli/kanban_db.py`,
`VALID_STATUSES`): `triage/todo/scheduled` → Todo, `ready/running` → In
Progress, `blocked` → Blocked, `review` → Review, `done/archived` → Done.
Клик по карточке открывает модалку с лентой `task_events`, `task_runs` и
`task_comments` этой задачи — «кто кому что передал и что вызвал» видно по
факту, без отдельного механизма трекинга.

## Почему так, а не через мост

Hermes работает в отдельном Docker-контейнере (`DOCS/decisions/029`), и
`kanban.db` лежит там же — казалось, нужен мост (HTTP-эндпоинт внутри
контейнера или `docker exec`). Моста не потребовалось: `docker-compose.hermes.yml`
уже монтирует домашнюю папку контейнера на диск проекта (`./hermes-home:/opt/data`),
а `kanban.db` лежит внутри неё — то есть файл и так уже на диске, рядом с
`server.js`, а не только внутри контейнера. Открывается он тем же `node:sqlite`,
которым `server.js` уже открывает свою собственную `DATA/.sessions.db`.

Открываем и закрываем базу на каждый запрос, а не держим один хэндл: Hermes —
сторонний процесс, который пишет в этот же файл, и держать читающий хэндл
между запросами незачем, а WAL-файл может подрасти между обращениями.

## Чем платим

- Доска обновляется раз в 5 секунд (опрос, как у Home/Chat), а не мгновенно —
  Hermes и OpenKarandash по-прежнему разные процессы.
- Если `hermes-home/kanban.db` ещё нет (Hermes-стек не поднят или ни одной
  задачи не заводили), вкладка показывает текст-заглушку вместо доски.
- Зависимость `beads-kanban-ui` убрана из `package.json`; в `package-lock.json`
  запись пока осталась — досчитывает её обычный `npm install`.
