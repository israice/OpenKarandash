# 023. Вкладку Graph убрали, карту проекта оставили

## Решение

Вкладки Graph в интерфейсе больше нет: кнопка `#graphButton`, блок `#graphView`,
полотно с силовой раскладкой, чипы видов, панель деталей узла и поиск по облаку
удалены. Папка `PROJECTS/Graph/` осталась на месте и продолжает делать всё
остальное — это не вкладка, а карта проекта:

| Что осталось | Кому нужно |
|---|---|
| `graph-vault.js` — сборка `DATA/vault/` (заметки на файлы, секции, функции, роуты, память о сессиях) | поиск, память о прошлых сессиях |
| `graph-search.js` + `search.js` — индекс FTS5 и поиск | `node PROJECTS/Graph/search.js "запрос"`, маршрут `/api/search` |
| `graph-files.js` — чтение и правка файла внутри корня | маршруты `/api/file/read`, `/api/file/write` |
| `file-editor.js` + `file-editor.css` — редактор файла (бывшая нижняя половина `graph.js`) | панель README во вкладке Book, панель файла в Chat, ноды-документы Flow |
| `md-editors.js`, `vendor/easymde/` | те же панели |

Маршрут `/api/obsidian/graph` тоже остался: карту по нему забирает уже не полотно,
а `file-editor.js` — из неё строится список связей узла и переходы по ним.

## Почему

Вкладкой не пользовались, а стоила она заметно: силовая симуляция O(n²) на кадр,
своя раскладка, зум, перетаскивание узлов, фильтр по видам в `localStorage` — около
480 строк клиента и 220 строк стилей, которые приходилось держать в согласии с
остальным интерфейсом при каждой правке разметки.

Удалять всю папку было нельзя: под вкладкой лежали три вещи, которыми живёт весь
проект, — vault, полнотекстовый поиск (им ищут и агенты, см. `AGENTS.md`) и общий
редактор файла. Правило `014` («раздел живёт в своей папке целиком») тут работает в
обратную сторону: у `PROJECTS/Graph/` просто больше нет вкладки, зато остались
механизмы, которые она когда-то принесла с собой.

## Чем платим

- **Имя папки пережило свою вкладку.** `PROJECTS/Graph/` теперь не раздел
  интерфейса, а карта проекта с поиском и редактором файла. Переименование задело
  бы `server.js`, смоук (тогда ещё живой), `AGENTS.md` и все решения, где путь уже назван, — цена
  выше выигрыша. Внутри папки имена уже честные: `file-editor.js`, а не `graph.js`.
- **`window.MissionGraph` стал `window.MissionFiles`.** Имя из решений `014` и `022`
  сменилось: контракт (`createFileEditor`, `nodeByPath`, `openFileModal`,
  `closeFilePanel`, `openFile`) тот же, зовут его те же четыре файла.
- **Карту теперь тянет редактор, а не вкладка.** Раньше узлы и связи приезжали при
  открытии Graph; теперь `file-editor.js` забирает их лениво — при первом открытии
  файла — и забывает по событию `map`, когда сервер пересобрал vault.
- **Список связей узла остался почти без применения.** Он рисуется только для узлов
  карты (у них есть `path`), а Book, Chat и Flow открывают файл по пути
  (`{ file, kind: 'file' }`) — у такого узла связей нет, и список пуст. Так было и
  до удаления вкладки: наполняло его только полотно. Механизм оставлен как есть —
  либо ему найдут применение, либо он уедет следующим решением.
