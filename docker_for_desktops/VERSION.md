         образа работает; добавлены xdg-utils, menu-xdg, gsettings;
         починены зависшие сессии в состоянии creating/starting
v0.0.4 - из сессии можно копировать наружу: текст из Linux попадает в
         буфер обмена браузера (было только в панель noVNC), файлы
         выкачиваются кнопкой Files; внутри сессии работают установки
         (sudo без пароля + интернет + рабочий dpkg), добавлены sudo,
         curl и ca-certificates
v0.0.5 - главная сессия как шаблон: одна сессия назначается главной
         (кнопка "Make main"), и все новые сессии делаются её копиями -
         с её файлами, настройками рабочего стола и установленными
         программами; уже созданные сессии не затрагиваются. Образ-шаблон
         (docker commit главной) публикуется автоматически, когда в главной
         меняются установленные программы; копия домашнего каталога
         снимается с главной при каждом создании сессии. API:
         POST /api/sessions/<id>/make-main, .../unmake-main,
         GET /api/template, POST /api/sessions с {"inherit": false}
v0.0.7 - в новые рабочие столы добавлены Node.js 22 и npm
v0.0.6 - добавлен opencode в новые сессии
