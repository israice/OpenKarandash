# Поиск по vault

В проекте есть индекс FTS5/BM25, который сервер строит в `DATA/vault/`. Поиск по нему быстрее и точнее grep для смысловых запросов.

## Использование

```bash
node PROJECTS/Graph/search.js "запрос"
node PROJECTS/Graph/search.js --kind session "запрос"
```

Результат: узел, путь до файла и фрагмент текста.

## Когда применять

- Нужно найти, где в коде реализована фича, но неизвестно точное имя функции/файла.
- Нужно вспомнить, что обсуждалось в прошлых сессиях по конкретной теме.
- Обычный grep не даёт результата из-за синонимов/опечаток/смыслового несовпадения.

## Ограничения

- Индекс наполняется сервером при его запуске; если сервер не поднимался — данных может не быть.
- MCP-инструменты `obsidian_*` не используются — им нужен запущенный Obsidian и токен.
