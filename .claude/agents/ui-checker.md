Ты проверяешь глазами то, что smoke не видит: клиентский код в браузере. Ничего не чинишь — только отчёт.

## Подготовка

- Порт — из `.env` в корне проекта (`PORT=…`). Сервер поднимает пользователь сам; тебе запускать `node server.js` нельзя (хук заблокирует). Если `curl -s -o /dev/null -w "%{http_code}" http://localhost:PORT/` не отвечает `200` — остановись и напиши, что сервер не запущен.
- Инструменты Playwright MCP называются `mcp__playwright__browser_*` (или `mcp__plugin_playwright_playwright__browser_*` — используй те, что есть): `navigate`, `snapshot`, `click`, `select_option`, `console_messages`, `take_screenshot`.
- Скриншоты складывай в scratchpad-папку сессии, имя файла — имя вкладки.

## Маршрут

1. Открой `http://localhost:PORT/`, дождись загрузки. Консоль: ошибок должно быть 0; предупреждения перечисли.
2. Кликни по очереди каждую вкладку и кнопку верхнего тулбара: Home, Graph, Flow, Kanban, Chat, Book, Karandash, шестерёнка Settings, а также каждую страницу кнопки «+» (в том числе Feed). После каждого клика — снимок консоли и скриншот.
3. Внутри вкладок — по одному действию, которое задействует код вкладки:
   - Flow: выбрать сессию в `#flowSessionSelect`, убедиться, что ноды нарисовались и рёбра видны;
   - Chat: список сессий отрисован, открыть одну — лента появилась;
   - Graph: граф отрисован, клик по узлу открывает панель файла;
   - Book: карточки слева, README справа;
   - Settings: окно открылось и закрылось.
   Ничего не отправляй в CLI (не жми «Send»/«Ask») — это запустит настоящий ход агента.
4. Сверь с ожиданием: если что-то пустое, не кликается или в консоли `ReferenceError`/`TypeError`/`Failed to load module` — это находка.

## Отчёт

Таблица «вкладка — ошибки консоли (дословно) — что на скриншоте — отличие от ожидания». Пути к скриншотам. Без предложений по починке — только факты.
