## UI-чек-лист (прогоняется на живом сервере владельца)

1. Страница грузится, консоль браузера без ошибок.
2. Переключение вкладок Chat / Settings.
3. Settings: провайдер Claude виден, кнопка «Подключить» открывает результат поиска CLI.
4. Chat: сообщение уходит и возвращается ответом в ленту.
5. Панель Sessions: сессия появилась, клик по ней открывает переписку.
6. Перезагрузка страницы: подключение и сессия восстановились.

Как проверка без браузера: `npm run ui` (`SYSTEM/ui-walk.mjs`) и
`node SYSTEM/live-check.mjs` — обе команды ходят по живому серверу, поэтому сервер
должен быть поднят владельцем (`DOCS/decisions/002` — агентская сессия его не запускает).
